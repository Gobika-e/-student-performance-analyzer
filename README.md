# -student-performance-analyzer
Student Performance Analyzer

About the Project

Student Performance Analyzer is a Python-based project used to manage student details and analyze their academic performance.

Features

- Add student details
- View student reports
- Search student records
- Update student marks
- Delete student records
- Calculate class summary
- Display student rankings
- Export reports to CSV
- Save and load data using JSON

Technologies Used

- Python
- JSON
- CSV

How to Run

1. Open the Python program in a Python compiler.
2. Run the program.
3. Select an option from the menu.
4. Enter student details and marks as required.
